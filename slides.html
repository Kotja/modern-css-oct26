Next-Gen CSS Animations

Replacing heavy JavaScript motion libraries with declarative native CSS.

The motion lives in CSS. The page does not run a library on every frame.

Open on the title. One sentence: these five jobs used to need a motion library, and each one is now a CSS declaration. Then go to the list.

Instead of a motion library

Five jobs CSS can own

  • view() reveals an element as it enters
  • scroll() tracks the scrollbar
  • allow-discrete fades out, then removes
  • interpolate-size opens to height: auto
  • linear() writes a bounce as points
About one minute. Name the five replacements, then switch to the playground for each one. Do not teach reduced motion, contrast, or layout here.

01 · Instead of ScrollTrigger

Reveal as it enters

.card {
  animation: reveal auto linear both;
  animation-timeline: view();
  animation-range: entry 0% entry 100%;
}

@keyframes reveal {
  from { opacity: 0; transform: translateY(72px) scale(0.92); }
  to { opacity: 1; transform: none; }
}
About four minutes. Open lab 01 and scroll. animation-duration is auto because the timeline is the scroll, not a clock. Scroll back and the entrance reverses.

02 · Instead of a scroll listener

Progress follows the scrollbar

.bar {
  transform-origin: left center;
  animation: grow auto linear both;
  animation-timeline: scroll(root);
}

@keyframes grow {
  from { transform: scaleX(0); }
  to { transform: scaleX(1); }
}

view() follows an element. scroll() follows the scroller.

About two minutes. Open lab 02. Nothing in JavaScript measures the scrollbar.

03 · Instead of mount and unmount

Fade closed, fade open

.menu {
  opacity: 1;
  transition-property: opacity, display;
  transition-duration: 400ms;
  transition-behavior: allow-discrete;
}
.menu.closed { opacity: 0; display: none; }
@starting-style { .menu { opacity: 0; } }

The pill stays put. It is taken out of the flow with position: absolute.

About three minutes. Open lab 03 and toggle the menu. The fade finishes before display: none. @starting-style fades it back in. Point at the pill: it does not jump.

04 · Instead of measuring height

Open to height: auto

:root { interpolate-size: allow-keywords; }

.panel {
  height: 0;
  overflow: clip;
  transition: height 500ms ease-out;
}
.item.open .panel { height: auto; }

Show this one in Chrome. It is not in every browser yet.

About three minutes. Open lab 04 and toggle Notes. JavaScript used to read the content height, then animate to that number.

05 · Instead of a spring helper

A curve written as points

.ball {
  animation: drop 1.1s
    linear(0, 0.05 8%, 1.28 42%, 0.82 62%, 1.08 80%, 1)
    both;
}

@keyframes drop {
  from { transform: translateY(-180px) scale(0.85, 1.08); }
  to { transform: translateY(0) scale(1); }
}

This is an easing curve, not a physics engine.

About two minutes. Open lab 05 and press Replay. The points overshoot and settle.

The five replacements

Native CSS instead of a library

  • view() for enter
  • scroll() for a scroll listener
  • allow-discrete and @starting-style for mount and unmount
  • interpolate-size for a measured height
  • linear() for a simple spring
